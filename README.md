# 📚 Data Structure Implementation in Java

> 자료구조의 동작 원리를 깊이 이해하기 위해 Java로 직접 구현하는 프로젝트입니다.

---

## 🧑‍💻 프로젝트 목표

- Java Collection Framework를 사용하지 않고 자료구조를 직접 구현
- 자료구조별 동작 원리 및 시간복잡도 이해
- 객체지향 설계(OOP) 능력 향상
